# Mizan

Private calorie, macro, training and weight tracker for Waleed and Safiya.

- Live app: https://w4luiz.github.io/mizan/
- Data: Supabase (shared household foods and recipes; private logs, weight and targets per person)
- Hosting: GitHub Pages from the `main` branch

Phase 1: logging, library, recipes, workouts, progress.
Phase 2: accounts, households, shared library, installable on phones.
